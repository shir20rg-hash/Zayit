# סדר הלימוד — APK אופליין

אפליקציית Android עצמאית למעקב לימוד ש״ס בבלי וירושלמי.

- בחירת מסכת וטווח דפים
- יעד מתאריך עד תאריך, עברי או לועזי
- לוח עברי מחושב מקומית ללא טבלת 100 שנה
- יומן דיווחים
- חישוב קצב, פער והתקדמות
- תזכורת מקומית כשהעדכון מתעכב או כשנוצר פער
- עיצוב כהה/זהב/זית בהשראת זית
- ללא הרשאת אינטרנט

הפרויקט נשמר כ-ZIP בענף זה לצורך Build מבודד, ואינו משנה את אפליקציית זית עצמה.
